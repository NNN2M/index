# 🤖 Telegram Bot - Gemini 2.5 Flash

بوت تيليجرام احترافي مدعوم بـ Gemini 2.5 Flash AI

## 🚀 التثبيت السريع

```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. إعداد المتغيرات
cp .env.example .env
# عدّل .env وضع التوكنات الخاصة بك

# 3. تشغيل البوت
python bot.py
```

## 🔑 الحصول على التوكنات

- **Telegram Bot**: تحدث مع [@BotFather](https://t.me/botfather)
- **Gemini API**: [Google AI Studio](https://aistudio.google.com/app/apikey)
